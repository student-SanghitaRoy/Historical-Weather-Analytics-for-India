TROUBLESHOOTING (Windows) - the problems seen most often, and the fix

1. "Could not open requirements file" / "File does not exist: app.py"
   You are one folder too high or too low. The correct folder contains app.py, setup.bat and requirements.txt.
   In PowerShell:  dir   (you must see app.py)  -  if you only see another folder, run:  cd <that folder>

2. "No module named pytest" (or streamlit, scipy, ...)
   The libraries went into the wrong Python. Use the project's own environment and install with python -m pip:
        venv\Scripts\activate
        python -m pip install -r requirements.txt
   (the prompt must start with (venv)). Or just double-click setup.bat.

3. PowerShell says "running scripts is disabled" when activating venv
   Run once in that window:   Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
   Then:  venv\Scripts\activate

4. Download stops with "Hourly API request limit exceeded"
   Normal. The free service has limits. Run  download_data.bat  (or  python scripts/prefetch_india.py --auto ) and leave it open;
   it waits and continues by itself. Finished locations are never downloaded again.

5. India overview says "No weather data downloaded yet"
   The data is stored in  data_cache\india  NEXT TO app.py. Check that folder exists and has .csv files.
   Always start the app from the project folder (run_app.bat does this). To explore without data, tick "Demo mode" in the left sidebar.

6. The maps show a grey or blank background
   The map background tiles come from OpenStreetMap and need internet. The dots and data do not. Record a backup video for presentations.

7. Windows shows a blue "protected your PC" screen for .bat files
   Click "More info", then "Run anyway".

8. "Address already in use" or the browser does not open
   Another copy of the app is running. Close the old terminal window (Ctrl+C) and start again, or open http://localhost:8501 manually.

9. "ConnectionResetError: [WinError 10054]" lines in the terminal
   Harmless Windows message when a browser tab reloads or closes. Ignore it.

10. The app shows "Your selection has changed"
   You changed a choice but did not press Load analysis. Press it.

11. "Could not load data" when choosing measurements other than temperature and rainfall (for example maximum temperature)
   Those are not in the downloaded dataset and need a live request to Open-Meteo (internet, and the hourly limit applies).
   Stay with Mean temperature and Precipitation for offline use.

12. Tests fail after extracting a new version
   Delete files that no longer exist in the new version (for example the old pages folder and tests\test_app.py / tests\test_pages.py),
   then run:  python -m pip install -r requirements.txt   and   python -m pytest -q

13. You moved or renamed the project folder
   Move it as a whole, including data_cache. Create a new venv (run setup.bat) because venv folders do not survive being moved.

If something else goes wrong: copy the full error text (not a screenshot of part of it) and send it to your assistant, together with
the command you ran and the folder you were in.
